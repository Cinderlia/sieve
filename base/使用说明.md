Sieve（旧名symex）
一款基于witcher的符号执行辅助工具，能够搭配witcher的fuzz完成符号执行，目前仅对PHP语言进行适配。

使用说明：
在容器里配置服务器
``bash
# 启动服务器
service apache2 start
mysqld --daemonize
# 调度器配置
echo 1 > /proc/sys/kernel/sched\_child\_runs\_first
echo core > /proc/sys/kernel/core\_pattern
# CPU性能模式
for fn in /sys/devices/system/cpu/cpu\*/cpufreq/scaling\_governor; do
   echo performance > $fn
done
# 设置 DISPLAY
export DISPLAY=:0
``

然后，创建一个文件夹，存放配置文件和测试结果。
配置witcher，按照使用说明填写witcher\_config.json文件。
配置爬虫，填写initial\_url\_config.json文件，大部分情况下保持默认即可。
使用以下命令，运行修改后的爬虫，如果服务器没有图形化，可以选择xvfb。
``bash
python3 /helpers/initial\_url/main.py http://127.0.0.1/dvwa/ ./ /app/dvwa/ --start-crawler --no-headless --timeout 4h --xvfb
``
参数解析：待测应用url、工作文件夹（各类配置文件所在的文件夹）、待测应用文件夹、启动爬虫、无头模式、时长控制、虚拟图形化

爬虫会在工作目录生成request\_data.json文件，存放爬到的数据。
在工作目录新建AST文件夹，然后运行下面的命令生成待测应用的AST文件。
``bash
\~/phpjoern/php2ast -n nodes.csv -r rels.csv /app/dvwa
``
得到nodes.csv和rels.csv，然后使用下面的命令生成cpg\_edges.csv文件。
``bash

\~/joern/phpast2cpg nodes.csv rels.csv

``
将三个AST文件都置入AST文件夹。

配置sieve，填写sieve\_config.json（或symex\_config.json）文件
使用以下命令启动witcher，sieve会同时开始工作。
``bash
p --testver sieve
``


额外说明：
使用以下命令开始记录覆盖率文件，覆盖率文件会生成在/dev/shm/coverages目录下。
``bash
touch /tmp/start\_test.dat
``
使用以下命令，整合覆盖率文件，整合后的覆盖率文件会生成在/tmp/coverages目录下。
``bash
python3 /codecov\_conversion.py
``
